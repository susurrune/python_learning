# Python 学习之旅 🐍

> 这是一个 Python 基础使用练习项目，记录了学习 Python 过程中的各种练习代码和学习笔记。

## 📋 项目介绍

本项目是个人 Python 学习的完整记录库，涵盖从基础语法到高级应用的多个学习领域。通过编写实践代码和记录学习笔记，逐步深化 Python 编程能力。

### 项目特点
- 📚 **系统学习**：从基础到进阶的完整学习路径
- 💻 **实践代码**：每个知识点都配备相应的代码示例
- 📖 **学习记录**：详细的学习笔记和总结
- 🔗 **多个领域**：涵盖网络编程、爬虫开发等实际应用

## 🎯 学习内容概览

### 📌 Python 基础
掌握 Python 编程的基本概念和语法，包括：
- 变量、数据类型和运算符
- 控制流程（条件语句和循环）
- 函数定义和调用
- 列表、字典、集合等数据结构
- 面向对象编程（类、继承、多态）
- 异常处理和调试技巧
- 内置模块和标准库的使用

### 🕷️ Python 网络爬虫
学习如何使用 Python 进行网络数据采集：
- 理解 HTTP 请求原理
- 使用 `requests` 库获取网页内容
- 用 `BeautifulSoup` 解析 HTML
- 用正则表达式提取数据
- 使用 `Selenium` 处理动态网页
- 爬虫礼仪和 robots.txt 规则
- 数据存储（CSV、JSON、数据库）
- 反爬虫应对策略

### 🌐 Python 网络编程
深入学习网络通信编程：
- Socket 编程基础（TCP 和 UDP）
- 客户端-服务器架构
- HTTP 协议理解和实现
- 并发编程（多线程、多进程、异步编程）
- REST API 设计和实现
- Web 框架（Flask、Django 等）
- 网络安全基础

### 📚 书籍学习记录
记录从各类 Python 学习书籍中获得的知识和经验。

## 🚀 快速开始

### 环境要求
- Python 3.7+
- 依赖包（见 requirements.txt）

### 安装依赖
```bash
# 克隆项目
git clone https://github.com/susurrune/python_learning.git
cd python_learning

# 安装依赖（如有）
pip install -r requirements.txt
```

### 查看学习内容
```bash
# 进入相应目录查看代码和笔记
cd python基础/
cd python网络爬虫/
cd python网络编程/
```

## 📖 使用说明

1. **按目录学习**：根据学习进度选择对应目录的内容
2. **阅读代码**：每个代码文件都有注释说明
3. **动手实践**：尝试修改代码并运行，加深理解
4. **查看笔记**：阅读学习笔记总结关键概念
5. **完成练习**：尝试独立完成相关练习题
